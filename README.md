# 🤖 AI Business Automation Agent

An enterprise-style AI Business Assistant built with Python, Gemini, LangGraph, LangChain, SQL and Streamlit.

The system understands employee requests and routes them to the appropriate capability such as policy search, employee database queries, calculations or business workflows.

---

## 🚀 Overview

The AI Business Automation Agent is designed as a centralized assistant for common employee and business requests.

Instead of sending every question to the same system, an LLM-based router determines the user's intent and directs the request to the appropriate processing module.

### Core Flow

```text
Employee Request
       ↓
   LLM Router
       ↓
 ┌─────┬─────┬────────────┬──────────────┐
 ↓     ↓     ↓            ↓
 RAG   SQL Calculator   Workflow
 ↓     ↓     ↓            ↓
Policy DB  Math      Business Logic
 └─────┴─────┴────────────┴──────────────┘
                 ↓
             Validation
                 ↓
            Final Response


✨ Features
📚 Policy Q&A

Provides answers from company policy documents.

Current example policies include:

Work From Home Policy
Leave Policy
Travel Policy
Expense Policy
IT Policy

The current lightweight retrieval system identifies relevant policy sentences using text matching.

👥 Employee Data

Uses a SQLite database containing demo employee records.

The system can answer questions such as:

Show me employees from the IT department

Natural-language questions are converted into SQL queries and executed through a read-only SQL tool.

🧮 Business Calculator

Supports basic business calculations from natural-language requests.

Examples:

What is 4000 multiplied by 3?
What is 500 plus 250?
What is 1000 divided by 5?
⚙️ Business Workflow Automation

Identifies operational requests and generates structured workflow responses.

Example:

My company laptop was lost.

The workflow can provide:

Process
Issue
Required Action
Status
Simulated Ticket ID
🔀 LLM-Based Routing

Gemini is used to classify incoming requests into:

rag
sql
calculator
workflow
unknown

This allows the application to select the appropriate processing path automatically.

✅ Validation

A validation layer checks the output generated by the different modules before presenting the final response.

⚙️ Installation

1. Clone the repository
git clone https://github.com/akashpalve1172/AI-Business-Automation-Agent.git
2. Open the project
cd AI-Business-Automation-Agent
3. Create a virtual environment

Windows:

python -m venv venv
4. Activate the environment
.\venv\Scripts\Activate.ps1
5. Install dependencies
pip install -r requirements.txt
🔑 Environment Variables

Create a .env file in the project root:

GOOGLE_API_KEY=your_gemini_api_key

Do not commit the .env file to GitHub.

It is included in .gitignore.

🗄️ Database Setup

The project includes a demo SQLite database.

To create or recreate the database:

python database_setup.py

The database contains sample employee information for demonstration and testing purposes.

▶️ Run the Application

Start Streamlit:

streamlit run app.py

Then open: http://localhost:8501

🔐 Security Considerations

The SQL tool is designed as a read-only demonstration tool.

It restricts database operations and blocks destructive SQL statements such as:

INSERT
UPDATE
DELETE
DROP
ALTER
CREATE

API credentials are stored in environment variables rather than source code.

📌 Project Scope

This repository is an enterprise-style demonstration project.

The included TechNova Solutions policy documents and employee records are demo data created for development and testing.

The workflow ticket IDs are simulated and do not represent integration with a real Jira, ServiceNow or enterprise ticketing system.

The project currently does not include production authentication, role-based access control, or deployment infrastructure.
